# Repository Structure

This document describes the public content layout for the Aegis releases repository.

## Top-Level Files

- `README.md` — official public-facing project overview and repository purpose
- `CHANGELOG.md` — template and running log of release-level changes
- `RELEASE_NOTES_TEMPLATE.md` — standard template for publishing release notes
- `latest.json` — JSON version manifest example for update distribution
- `latest.yml` — YAML update metadata template for electron-updater compatible channels
- `SECURITY.md` — security disclosure and handling policy
- `SUPPORT.md` — support process and support boundaries
- `RELEASE_POLICY.md` — release versioning and publication governance
- `UPDATE_MANIFESTS.md` — manifest field requirements and publication rules
- `INTEGRITY_VERIFICATION.md` — integrity artifact requirements and verification guidance
- `REPOSITORY_STRUCTURE.md` — this structure reference document

## GitHub Metadata

- `.github/ISSUE_TEMPLATE/bug_report.md` — standard bug reporting template
- `.github/ISSUE_TEMPLATE/feature_request.md` — standard feature request template
- `.github/ISSUE_TEMPLATE/config.yml` — issue intake configuration and contact links
- `.github/workflows/release.yml` — release publication workflow
- `.github/CODEOWNERS` — default ownership mapping for repository files

## Scope Reminder

This repository is dedicated to release communication artifacts and documentation.

It does not include source code or software development internals.
