# Support Policy

## Purpose

This document explains how to request support for Aegis release artifacts, update manifests, and public documentation contained in this repository.

## Supported Request Types

- Release package issues
- Update manifest issues
- Release note clarifications
- Documentation corrections
- Security assessment/reporting workflow questions related to published materials

## Request Channels

- Use the Bug Report template for defects
- Use the Feature Request template for improvements
- Use security reporting channels for potential vulnerabilities

## Required Information

Please include:

- Affected version
- Clear problem statement
- Steps to reproduce (if applicable)
- Expected behavior
- Actual behavior
- Impact summary

## Response Guidance

Support responses are best-effort and prioritized by impact and reproducibility.

## Scope Boundaries

This repository is not intended for source code development contributions or internal implementation support.
