# Security Policy

## Scope

This repository is used for Aegis public releases, update manifests, release notes, and documentation.

It does not contain source code.

## Reporting a Vulnerability

If you identify a potential security issue related to released software packages, update artifacts, integrity metadata, or published documentation, do not post full exploit details in public issues.

Use private disclosure through repository security reporting channels.

When reporting, include:

- A concise summary of the issue
- Affected release version(s)
- Potential impact
- Reproduction details
- Any available evidence

## Disclosure Process

1. Maintainers acknowledge receipt.
2. Maintainers triage and validate the report.
3. Maintainers determine severity and remediation scope.
4. Affected release documentation is updated.
5. Public disclosure is coordinated after remediation guidance is available.

## Response Targets

- Initial acknowledgement target: within 5 business days
- Triage status target: within 10 business days

These targets are goals and may vary depending on report complexity.

## Out of Scope for This Repository

- Requests for internal implementation details
- Source code review requests
- Proprietary architecture disclosure requests
